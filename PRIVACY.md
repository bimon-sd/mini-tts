# 隐私政策 / Privacy Policy

**最后更新：2026年4月**

## 我们收集什么 / What We Collect

Mini TTS 是一款本地优先的语音合成工具。我们**不收集**你的文字内容、语音输入或任何个人隐私信息。

为改进产品，我们收集**有限的匿名使用数据**，包括：

| 数据类型 | 说明 |
|---------|------|
| 设备 ID | 随机生成的匿名标识符，存储在本地，不与设备硬件绑定 |
| 应用打开事件 | 统计应用启动次数 |
| 播放按钮点击 | 统计功能使用频率 |
| 会话时长 | 应用关闭时统计使用时长（秒），不含任何行为详情 |
| 错误日志 | API 调用失败时的错误代码（不含敏感信息） |

**我们不收集：** 输入文本、API Key（仅保存在本地）、语音文件、音频内容、IP 地址、位置信息。

## 数据存储与安全 / Storage & Security

- 数据存储在 **Supabase**（PostgreSQL 数据库服务提供商），位于美国区域。
- 所有数据传输采用 HTTPS 加密。
- 数据库访问权限已配置为服务端角色，前端 API Key 为只读权限。
- 数据保留期限：**24 个月**，到期后自动清除。

## 你的权利 / Your Rights

- **撤回同意：** 随时删除本地存储的匿名标识符（删除应用即可清除本地记录）

# Privacy Policy (English)

**Last updated: April 2026**

## What We Collect

Mini TTS is a local-first text-to-speech application. We **do not collect** your text input, voice recordings, or any personal privacy information.

To improve the product, we collect **limited anonymous usage data**:

| Data Type | Description |
|-----------|-------------|
| Device ID | Randomly generated anonymous identifier, stored locally, not bound to hardware |
| App open events | Counts of application launches |
| Play button clicks | Feature usage frequency |
| Session duration | Time spent in seconds when closing the app, no behavioral details |
| Error logs | Error codes from API failures (no sensitive information) |

**We do NOT collect:** Input text, API Keys (stored only locally), voice files, audio content, IP addresses, or location data.

## Data Storage & Security

- Data is stored in **Supabase** (PostgreSQL cloud database), hosted in the US region.
- All data transmission uses HTTPS encryption.
- Database access is configured with service-role read-only permissions for the frontend key.
- Data retention period: **24 months**, after which data is automatically deleted.

## Third-Party Services

| Provider | Purpose | Privacy Policy |
|----------|---------|----------------|
| Supabase | Telemetry data storage | https://supabase.com/privacy |
| Microsoft Azure | Speech synthesis (requires user-provided API key) | https://privacy.microsoft.com |
| Microsoft Edge TTS | Speech synthesis (no API key required) | https://privacy.microsoft.com |
| Tailwind CSS | Frontend styling (CDN) | https://tailwindcss.com |

## Your Rights

- **Opt-out:** Click "Disagree" on first launch — no data will be sent
- **Withdraw consent:** Delete the app to clear local identifiers at any time
- **Data deletion request:** Email **bimongl@gmail.com**, processed within 7 business days
- **Offline use:** TTS functionality works without network (Edge TTS)

## Children's Privacy

Mini TTS is not intended for children under 13. We do not knowingly collect personal information from minors.

## Changes to This Policy

Significant changes will be communicated via in-app notices or official website announcements.
