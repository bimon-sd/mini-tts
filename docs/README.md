# G-Reader 文档

## 产品简介

G-Reader 是一款 Windows 桌面文字转语音（TTS）工具，支持 Azure 神经网络语音与 Edge TTS 双引擎。操作简单，产出快速，适合制作有声书、会议记录转语音、内容批量配音等多种场景。

**核心定位：快速、免费、零门槛。**

---

## 系统要求

- Windows 10/11（64位）
- 无需注册账号
- 无任何依赖（内置 Python 运行环境）

---

## 安装与卸载

**安装：**
1. 下载 `G-Reader-Setup.exe`
2. 双击运行，按向导完成安装
3. 从桌面快捷方式启动

**卸载：**
- 通过 Windows「设置 → 应用 → 已安装的应用」，找到 G-Reader 点击"卸载"
- 或运行安装目录下的 `uninstall.exe`

---

## 双引擎说明

G-Reader 内置两个语音引擎，可自动切换：

### Edge TTS（免费，无需配置）

微软 Edge 浏览器同款语音引擎，**免注册、免付费**，打开即用。

**优点：** 免费、零门槛、操作简单、出品速度快
**缺点：**
- 支持音色较少
- 非官方接口，受微软官方限流影响，高峰期可能出现排队或失败
- 长期稳定性不如 Azure

**适用场景：** 初次体验、短文本、快速测试

---

### Azure 神经网络语音（高质量）

微软 Azure 认知服务语音合成，音质达到行业顶尖水平。

**优点：**
- 支持 SSML 标签，可精确控制语速、音量
- 支持 0.5 秒 / 1 秒人工停顿标注
- 音质稳定，无限流问题，适合批量产出
- 对本地硬件零要求，产出速度快

**缺点：**
- 情绪表达较为平稳，无明显语调起伏（神经网络语音共同特性）
- 需要注册 Microsoft Azure 账号并获取 API Key

**适用场景：** 有声书制作、会议记录转语音、内容批量配音、长期稳定使用

## Azure 账号注册指南

### 免费福利

Azure 语音服务提供**免费层级（Free Tier）**：
- **每月 50万字符**免费额度
- 额度按月计算，每月1日自动重置
- 额度耗尽后**不会自动扣费**，服务自动暂停，下月恢复
- 注册时会有 **1美元预授权扣款**（验证信用卡用），验证完成后**自动返还**

---

### 注册步骤

**第一步：访问 Azure 官网**

打开 [azure.microsoft.com/free](https://azure.microsoft.com/free)，点击"免费开始"。

**第二步：登录微软账号**

使用您的 Outlook 或 Hotmail 邮箱登录。若没有账号，点击"创建一个"进行注册。

**第三步：填写个人信息**

按页面提示填写姓名、国家/地区等信息，**选择距离自己较近的区域**。

> 💡 注册信息中的国家/地区会影响可用的语音服务，建议选择您实际所在的国家或常用区域。

**第四步：绑定信用卡**

页面会要求绑定信用卡（支持 Visa / Mastercard 等）。输入信用卡信息后，银行会进行一笔小额预授权验证（约1美元），**验证完成后自动退还**，不是实际扣费。

> ⚠️ **重要：** Azure 语音服务**不会**在免费额度用尽时自动扣费。当月额度耗尽后服务自动停止，次月1日自动恢复。请放心使用，不会产生意外账单。

**第五步：创建语音服务资源**

1. 登录 Azure Portal 后，在搜索框输入"语音服务"
2. 点击"创建语音服务"
3. 选择订阅（选择"免费试用"即可）
4. 填写资源组（选"新建"，起个名字如"greader-tts"）
5. **区域选择距离自己较近的区域**（如 East Asia、Southeast Asia 等）
6. 输入资源名称（任意，如"greader"）
7. 点击"审阅并创建" → "创建"

**第六步：获取 API Key**

1. 资源创建完成后，进入"密钥和终结点"
2. 复制 **KEY 1**（或 KEY 2，两者皆可）
3. 记录区域名称（如"eastasia"）

**第七步：在 G-Reader 中配置**

1. 打开 G-Reader → 点击右上角⚙️设置图标
2. 勾选"Enable Azure TTS"
3. 粘贴 API Key
4. 区域选择对应节点（与第五步创建资源时选的一致）
5. 点击 Save 保存

## 使用说明

### 基本操作流程

1. **输入文字**：在文本框输入或粘贴要转换的文字
2. **选择语言**：从语言下拉菜单选择目标语言
3. **选择音色**：每个语言提供多款音色（男/女/儿童等）
4. **设置保存路径**：点击"Save To"选择输出文件夹
5. **点击 Execute**：等待合成完成，文件自动保存为 WAV

### 局部语速控制（仅 Azure TTS）

1. 选中文本框中需要变速的文字
2. 拖动 Rate 滑块到目标速度（如 0.8x 表示放慢，1.2x 表示加快）
3. 点击 Apply 插入标记

### 局部音量控制（仅 Azure TTS）

1. 选中文本框中需要调音量的文字
2. 拖动 Volume 滑块到目标音量（如 0.5x 表示降低，1.5x 表示提高）
3. 点击 Apply 插入标记

### 人工停顿（仅 Azure TTS）

- 点击 `[[0.5s]]`：在光标位置插入 0.5 秒停顿
- 点击 `[[1s]]`：在光标位置插入 1 秒停顿

### 字符数量监控

文本框右下角实时显示当前字符数量，便于预估产出时长。

### PDF 文件支持

支持直接拖拽 PDF 文件或使用"Open"按钮加载，程序将自动提取文本内容。

## 常见问题

**Q：Edge TTS 为什么有时候会失败？**
A：Edge TTS 走非官方接口，依赖微软服务器，受官方限流策略影响。高峰期可能出现排队或失败，建议此时使用 Azure TTS。

**Q：Azure 会不会在免费额度用完后自动扣费？**
A：不会。Azure 的策略是**停止服务**，绝不会自动扣费。您可以放心使用，不会产生意外账单。

**Q：为什么语音听起来没有情绪起伏？**
A：Azure 神经网络语音追求的是音质稳定性和自然度，在情绪表达上相对平稳。这是当前神经网络语音技术的共同特性，非 G-Reader 软件问题。

**Q：如何获得更自然的人声效果？**
A：建议搭配语速局部控制和人工停顿使用，在关键段落适当放慢或停顿，可以大幅提升听感。
